    🎮 ゲーム登録フォーム

    GitHub Pages・itch.io・自分のサイトなど、https で公開されている URL。

    ℹ️ サイトによってはサイト内での表示（埋め込み）を拒否するため、その場合プレイヤーは「新しいタブで開く」で遊びます。自分のゲームを確実にサイト内で遊んでもらいたいなら「ファイルで登録」がおすすめです。

    HTML 1枚のゲームはそのまま選べば自動で zip にします。画像や音声がある場合は、index.html を含むフォルダごと zip にしてください。

    プレビュー

    よくある質問

    審査にはどれくらいかかりますか？

    自動チェックは送信から数十秒で終わり、結果が Issue にコメントされます。その後の管理者による確認は、目安として 3 日以内です。公開されると Issue にコメントが付き、GitHub から通知メールが届きます。

    お金はかかりますか？ GitHub のアカウントは必要ですか？

    登録も掲載も無料です。送信には GitHub のアカウント（無料）が必要です。お持ちでない場合は github.com/signup から数分で作れます。

    どんなゲームを登録できますか？

    ブラウザだけで動く HTML / JavaScript のゲームです。ファイルで登録する場合は zip で 20MB まで（展開後 50MB・500 ファイルまで）、中に index.html が必要です。外部への不正な通信や個人情報の収集をするもの、他人の権利を侵害するものは登録できません。

    URL とファイル、どちらで登録すればいいですか？

    すでに自分のサイトや itch.io などで公開しているなら URL が手軽です。ただしサイトによってはサイト内での表示を拒否するため、その場合は新しいタブで開いて遊ぶ形になります。まだ公開していない、またはサイト内で確実に遊んでほしい場合はファイルで登録してください。

    画像や音声があるゲームの zip はどう作りますか？

    Windows: ゲームのフォルダを右クリック →「圧縮先」→「ZIP ファイル」。Mac: フォルダを右クリック →「"フォルダ名"を圧縮」。フォルダの中に index.html がある状態で圧縮してください。

    著作権や権利はどうなりますか？

    ゲームの著作権は作者のあなたに残ります。GAME WORLD はサイト上での掲載・配信のためにだけ使います。ファイル登録の場合、ゲームのファイルはこのサイトの公開リポジトリに保存されるため、誰でも中身を見られる点にご注意ください。

    公開後に更新や削除はできますか？

    削除：サイトのゲーム詳細の下にある「このゲームの削除を依頼」から送信してください。登録したときと同じ GitHub アカウントで送ると、自動ですぐに削除されます。作者以外の方からの依頼（権利侵害の報告など）は、管理者が確認してから対応します。
    更新：いったん削除してから、同じゲームID で登録し直してください。

    上級者向け：Pull Request で直接追加する

    リポジトリを Fork し、games/<ゲームID>/ にゲームを置いて games.js の GAMES に1件追加し、Pull Request を送ってください。詳しくは README を参照。
