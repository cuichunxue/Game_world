03あなたのゲームを登録しよう

URL でも、ゲームファイルでも OK。管理者の確認後にサイトに並びます。

  1. 1

    フォームに入力

    公開済みのゲームなら URL、まだなら HTML / zip ファイル を選んで、ゲームの情報を入力します。

  2. 2

    GitHub で送信

    入力内容が入った GitHub の画面が開くので、送信ボタンを押すだけ。ファイルの場合は zip をドラッグ＆ドロップ。

  3. 3

    確認して公開

    自動チェックの結果がすぐ届きます。管理者が承認すると、数分でサイトに公開されます。

🎮 ゲーム登録フォーム

GitHub Pages・itch.io・自分のサイトなど、https で公開されている URL。

HTML 1枚のゲームはそのまま選べば自動で zip にします。画像や音声がある場合は、index.html を含むフォルダごと zip にしてください。
