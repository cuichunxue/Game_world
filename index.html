03あなたのゲームを投稿しよう

HTML 1枚で動くゲームなら、3ステップで公開できます。

  1. 1

    ゲームを置く

    リポジトリを Fork して games/<ゲームID>/index.html にゲームを置きます。自分のサイトで公開済みなら URL だけでも OK。

  2. 2

    カタログに登録

    games.js の GAMES に1件追加。初投稿なら CREATORS に自己紹介も。下のジェネレーターが便利です。

  3. 3

    Pull Request

    PR を送ってマージされたら公開完了！ GitHub Pages で自動的にサイトに並びます。
